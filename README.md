# 修仙道馆短视频脚本迭代技能（xiuxian-script-remix）

一个用于**真人剧情类短视频脚本快速迭代**的 WorkBuddy / Claude Skill。

把手上的爆款短视频（如"疯狂水世界""疯狂秘境"系列）当成**结构模板**，快速产出一版全新的修仙道馆题材脚本：结构不变、节奏不变，场景、人物、宝物、台词全部另编。

## 最省事的用法：丢个视频就行

**你只需要发来一个参考视频（可以附一句时长），技能会自动跑完整个流程并交付脚本，不需要任何额外说明。**

```
你：D:/视频/仙府.mp4 15秒
技能：自动分析节奏 → 判定结构类型 → 抽象节拍 → 重建内容 → 搜当天热点 → 输出完整脚本
```

自动执行的动作：

1. 分析视频时长、分辨率、场景切换点、关键帧
2. 按你给的时长（没给则按原片时长）规划分段点
3. 判定结构类型（排队亮宝型 / 上下铺祸水型 / 验宝定居所型）
4. 抽出纯功能骨架，丢掉全部具体内容
5. 从素材池里挑**没用过**的场景/人物/宝物/坐骑，重建一整版新内容
6. 按规范格式输出脚本，排队型自动标注上场位次
7. 过一遍自检清单后交付

## 它解决什么问题

短视频迭代最怕两种错：

- **逐词替换**：只把"火锅"改成"灵汤"、"公司"改成"宗门"——观众一眼看出是换皮，没有新意
- **推倒重编**：结构都改了，等于另写一集，失去爆款的可复用性

本技能提供的是**第三种正解**：

> **同结构 + 全新内容**

保留每拍的功能、顺序、因果链和节奏；场景、人物身份与外形、宝物道具、台词、坐骑、结尾画面——全部重建，一项不得复用。

自查句：*把新脚本每一拍和上一版对应拍放在一起，除"这一拍在干什么功能"外，还有什么是相同的？* —— 有任何一项雷同，就重写该项。

## 核心能力

| 能力 | 说明 |
|---|---|
| 零说明自动迭代 | 发视频即开工，自动完成分析→抽象→重建→交付全流程，无需反复确认 |
| 视频节奏分析 | `scripts/analyze_video.sh` 用 ffmpeg 自动提取时长、分辨率、场景切换点、均匀关键帧 |
| 结构类型识别 | 内置三种结构型速查表，拿到新视频先判型再动手 |
| 内容重建 | 场景池、人物身份池、宝物池、坐骑池 + 已用台账，逐项换新且不与往版重复 |
| 格式规范 | 严格脚本格式（时间码分段 + [画面] + [角色]（语气）台词 + 拍摄剪辑提示） |
| 排队位次标注 | 排队型视频自动标注第一位、第二位…与原片上场顺序一致 |

## 输出规格（硬性要求）

- 画幅：**9:16 竖屏，1080×1920**
- 画面：**无 UI、无文字、无字幕**（人物等级/境界只写进人物设定，不上屏）
- 时长：按用户指定的时长；未指定则与原视频一致（±0.5 秒）
- 台词：全部走口播配音，不依赖字幕传达信息，约 4~5 字/秒

## 目录结构

```
xiuxian-script-remix/
├── SKILL.md                        # 技能主文件：零说明自动迭代协议、工作流、规格、自检清单
├── references/
│   ├── format-spec.md              # 脚本格式模板、排队位次规范、结构类型速查、beat sheet 档案
│   └── rewrite-playbook.md         # 内容重建表、场景/人物/宝物/坐骑池、已用台账、结构模板
└── scripts/
    └── analyze_video.sh            # 视频节奏分析脚本（依赖 ffmpeg）
```

## 已知结构类型

| 结构类型 | 特征 | 代表视频 |
|---|---|---|
| 排队亮宝型 | 排队→亮宝→"到我了"→揭穿假货→"下去吧你"惩罚 | 疯狂水世界 / 疯狂秘境 / 疯狂洞天 |
| 上下铺祸水型 | 上层作→波及下层→祸水反噬→甩锅→弱者跑路 | 宿舍 |
| 验宝定居所型 | 验宝唱名→顶级居所 vs 破烂居所→撂话→坐骑跑路 | 仙府 / 不同仙府 |

## 安装

把 `xiuxian-script-remix` 文件夹放进你的 skills 目录：

```bash
# 用户级（对所有项目生效）
~/.workbuddy/skills/xiuxian-script-remix/

# 项目级（仅当前项目）
<项目根>/.workbuddy/skills/xiuxian-script-remix/
```

`scripts/analyze_video.sh` 需要本机已安装 `ffmpeg` / `ffprobe`。
