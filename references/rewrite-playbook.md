## 二、"工业化修仙缝合道具"生成法（本系列核心笑点）

公式：**修仙名词 + 现代物品形态/使用方式 = 缝合法宝**

已验证案例：
- 二手废丹榨汁机（= 破壁机，紫烟环绕）
- 仙泉饮水机（= 金色饮水机，龙纹出水）
- 带辅助轮的飞剑 / 手动挡竹蜻蜓 / 扫码共享单剑
- 电鳗发电机 → 修仙版可改"雷鳗蓄灵罐"（陶罐里关一只放电雷鳗）

生成套路（新脚本按此造新道具）：
1. 取原视频道具的功能（过滤、发电、饮水、照明、代步）
2. 套一层修仙包装：灵X、仙X、御X、聚X、X阵、X符
3. 缝合现代形态感描述：带把手/带轮子/插电→插灵石/带说明书→带符纸
4. 加一个"廉价感瑕疵"：二手、三手、组装、DIY、缺角、漏灵气

## 三、人物功能位（功能保留，身份重设）

**排队类视频额外要求：人物设定中必须逐条标注位次。**

| 功能位 | 常见位次 | 说明 |
|---|---|---|
| 主持验货者 | 不在队列 | 站在台上/台后，如守冢婆婆、验丹婆婆 |
| 高位者（获顶级待遇） | **第一位** | 第一个上场，验出顶级资质，获至尊居所虚影 |
| 倒霉者（被验出废品） | **第二位**（末位） | 后上场，被狼狈化，验出废资质，撂狠话后跑路 |
| 围观群众 | 队列中段 | 惊叹、议论，制造气氛 |

位次 = **原片的上场顺序**，必须照搬。若原片是三人排队，新版也要三人排队且位次一一对应。

| 原视频角色功能 | 修仙版角色 |
|---|---|
| 掌权/鉴定者（安检员、长老） | 威严长老/执法执事，口头禅"不对""下去吧你" |
| 得意的先来者（亮真宝） | 高境界修士（Lv.99 元婴期），炫耀缝合法宝 |
| 倒霉主角（假货被拆穿） | 低境界修士（Lv.20 筑基期），憨厚、贪小便宜 |
| 吃瓜群众（大妈+小姐姐） | 炉峰散修大妈、狐耳小妖女、看热闹的小道童 |

## 四、热点融入规则

1. 时机：写脚本前先 WebSearch 当日热点/热梗，挑 1~2 个
2. 融入优先级：台词玩梗 > 道具彩蛋 > 身份梗（见 SKILL.md 第 2 步）
3. 热梗必须"修仙化翻译"后再用，保持世界观完整（例：热梗"尊嘟假嘟"→可改为道号式吐槽"尊嘟假嘟诀"；热词"泼天的富贵"→"泼天的机缘"）
4. 时效性梗标注生成日期，方便用户判断是否可用
5. 结构、时间码、人物功能一律为热点让路——热点只能填进既有节拍的台词/道具槽位

## 五、节奏与台词经验值

- 节拍功能与上一版对齐，不增不减
- 台词全部重写，一句不沿用；只对齐情绪（被质疑/炫耀/撂狠话）
- 结尾爆点形式要与上一版不同（换坐骑、换喷出物、换跑路姿态）
- 反差原则：古风画面 + 工业破烂感道具，违和感越强越好笑
- **迭代底线**：逐拍自查"除功能外还有什么是相同的"，有任何一项雷同就重写该项
