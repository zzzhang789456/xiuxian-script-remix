# 修仙道馆短视频脚本迭代技能（xiuxian-script-remix）

一个用于**真人剧情类短视频脚本快速迭代**的 WorkBuddy / Claude Skill。

把手上的爆款短视频（如"疯狂水世界""疯狂秘境"系列）当成**结构模板**，快速产出一版全新的修仙道馆题材脚本：结构不变、节奏不变，场景、人物、宝物、台词全部另编。

## 它解决什么问题

短视频迭代最怕两种错：

- **逐词替换**：只把"火锅"改成"灵汤"、"公司"改成"宗门"——观众一眼看出是换皮，没有新意
- **推倒重编**：结构都改了，等于另写一集，失去爆款的可复用性

本技能提供的是**第三种正解**：

> **同结构 + 全新内容**

保留每拍的功能、顺序、因果链和节奏；场景、人物身份与外形、宝物道具、台词、坐骑、结尾画面——全部重建，一项不得复用。

自查句：*把新脚本每一拍和上一版对应拍放在一起，除"这一拍在干什么功能"外，还有什么是相同的？* —— 有任何一项雷同，就重写该项。

## 核心能力

| 能力 | 说明 |
|---|---|
| 视频节奏分析 | `scripts/analyze_video.sh` 用 ffmpeg 自动提取时长、分辨率、场景切换点、均匀关键帧，快速还原 beat sheet（节拍表） |
| 结构抽象 | 把原片每个节拍抽象成纯功能标签（如"验宝→唱名→顶级居所→打脸→撂话→跑路"） |
| 内容重建 | 提供场景池、人物身份池、宝物池、坐骑池 + 内容重建对照表，逐项换新且不重复 |
| 格式规范 | 严格的脚本输出格式（时间码分段 + [画面] + [角色]（语气）台词 + 拍摄剪辑提示） |

## 输出规格（硬性要求）

- 画幅：**9:16 竖屏，1080×1920**
- 画面：**无 UI、无文字、无字幕**（人物等级/境界只写进人物设定，不上屏）
- 时长：与原视频一致（±0.5 秒）
- 台词：全部走口播配音，不依赖字幕传达信息，约 4~5 字/秒

## 目录结构

```
xiuxian-script-remix/
├── SKILL.md                        # 技能主文件：工作流、规格、自检清单
├── references/
│   ├── format-spec.md              # 脚本格式模板、范例、参考视频 beat sheet 档案
│   └── rewrite-playbook.md         # 内容重建表、场景/人物/宝物/坐骑池、结构模板
└── scripts/
    └── analyze_video.sh            # 视频节奏分析脚本（依赖 ffmpeg）
```

## 安装

把 `xiuxian-script-remix` 文件夹放进你的 skills 目录：

```bash
# 用户级（对所有项目生效）
~/.workbuddy/skills/xiuxian-script-remix/

# 项目级（仅当前项目）
<项目根>/.workbuddy/skills/xiuxian-script-remix/
```

`scripts/analyze_video.sh` 需要本机已安装 `ffmpeg` / `ffprobe`。

## 使用示例

```
用户：根据 D:/视频/某某.mp4 做迭代

技能流程：
1. 跑 analyze_video.sh 提取节奏与关键帧
2. 抽出六拍功能骨架（验宝→唱名→顶级居所→打脸→撂话→跑路）
3. 场景、人物、宝物、台词、坐骑全部另编
4. 按格式输出脚本，逐拍自查雷同项
```
