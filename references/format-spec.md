# 脚本格式规范

## 输出模板

```markdown
《<标题>》<N> 秒短视频脚本，<N> 秒视频，9:16，1080P

场景设定：<一句话，修仙道馆世界的具体地点+氛围>

人物设定：
第一位（<角色A>）：<境界/Lv 备注>：<性格+外形特征>
第二位（<角色B>）：<境界/Lv>：...
第三位（<角色C>）：<境界/Lv>：...
（注：人物等级/境界仅为表演参考，画面无 UI 不上屏）

【0000 - 0005】
[画面] <镜头描述，含机位/动作/道具特写>
[<角色>]（<语气>）："台词"

【0005 - 0009】
...

拍摄剪辑提示：<镜头节奏、道具要求、表演要点>
```

## ⚠️ 排队类视频必写规范（强制）

**只要参考视频里存在"排队/依次上场"的情节，输出脚本必须在人物设定中明确标注每个人的排队位次：第一位、第二位、第三位……依次类推。**

具体要求：

1. **人物设定区必须逐条标位次**，格式：
   ```
   第一位（<角色名>）（<境界>）：<身份+外形+性格>
   第二位（<角色名>）（<境界>）：...
   第三位（<角色名>）（<境界>）：...
   ```
2. **位次 = 上场顺序**，必须与原视频一致：谁第一个被验/被叫号，就是第一位；谁最后上场被打脸，就排在最后
3. **台词段落的落点要与位次对应**：第一位的台词出现在靠前的节拍，末位者的台词出现在靠后的节拍
4. **末位者通常是被打脸的倒霉蛋**（该系列的固定笑点位置），位次要标清，避免拍摄时把出场顺序搞乱
5. 即使某位角色全片只有一句台词、或只是围观群众，只要在原片排队序列里有位置，就要标出位次

**示例（验宝定居所型）：**
```
人物设定：
第一位（掌炉真君）（Lv.140 化神期）：金线丹纹道袍，怀抱金葫芦，来请镇谷名剑——先上场，被验出顶级资质
第二位（小丹童）（Lv.18 炼气期）：粗麻短褐背破药篓，倔强嘴硬——后上场，被验出废资质并撂狠话
围观（验丹婆婆）（Lv.75 丹道散修）：主持验宝者，站在验宝台上，不算排队序列
（注：人物等级/境界仅为表演参考，画面无 UI 不上屏）
```

## 格式细则

1. **标题行**：书名号标题 + 总时长 + "9:16，1080P"。标题要朗朗上口、带修仙味（如《御剑下山》《疯狂秘境》《筑基记》）
2. **时间码**：`【0000 - 0005】`格式，秒为单位两位数，**必须对齐原视频 beat sheet 的时间点**，这是"节奏类似"的硬保证
3. **[画面]**：只描述镜头内可见的动作、表情、道具、机位；**禁止出现字幕/UI/花字描述**
4. **台词**：`[角色]（语气）："台词"`。台词是唯一的信息载体（因为无字幕），必须口语化、短促、有情绪
5. **口播时长换算**：中文口播约 4~5 字/秒。某段台词字数必须 ≤ 区间秒数 × 5，超了就删
6. **人物设定**：可写"（头顶 Lv.95）"式备注，但需在人物设定下加一行注明：`（注：人物等级/境界仅为表演参考，画面无 UI 不上屏）`；**排队类视频必须标注位次（见上）**
7. **拍摄剪辑提示**：3 句以内，点明快切节奏、缝合道具的"现代工业感 + 古风背景"违和要求、结尾动作的滑稽处理

## 范例（用户认可的原版格式）

《御剑下山》15 秒短视频脚本，15 秒视频，9:16，1080P

场景设定： 万丈悬崖边，云海翻腾。
人物设定：
剑宗宗主（Lv.95）：威严，背负长剑
剑修男（Lv.25）：脚踩黄色自行车形状的剑
剑修女（Lv.22）：脚踩带辅助轮的剑

【0000 - 0005】
[画面] 宗主拔出半截剑，指着剑修男怒斥。
[宗主]（威严质问）："剑修当一剑破万法！你踩个【扫码共享单剑】？飞到一半提示余额不足掉下去怎么办！"

【0005 - 0009】
[画面] 宗主转头看着剑修女，气得把手里的剑按了回去。
[宗主]（无语）："你那是什么？【带辅助轮的飞剑】？在天上飞你装四个轮子防侧翻吗！"

【0009 - 0015】
[画面] 宗主突然猛拍大腿，掏出一个竹蜻蜓戴在头上，表情比哭还难看。
[宗主]（悲愤）："策划你出来挨打！VIP10 专属飞行坐骑，居然是个【手动挡竹蜻蜓】，老夫飞一趟头皮都快搓秃了！"

拍摄剪辑提示： 多镜头快节奏切换，对话节奏紧凑，道具的建模一定要有现代工业感，与古风背景形成强烈违和感。最后宗主戴竹蜻蜓的动作要滑稽。

> 注：范例中【扫码共享单剑】【VIP10】等词在"疯狂水世界改写"场景下应换成修仙缝合说法（见 rewrite-playbook.md），范例保留原样仅为展示格式。

### 档案 A：《疯狂水世界》（视频一，18.8s，720x1280@30fps）

- 场景：末日水世界"第七廊桥"，排队过安检；安检员持红色扫描枪逐个检查行囊
- 节拍：
  - 0.0–3.0s 排队全景，安检员扫金西装男的"泥疙瘩"行李
  - 3.0–6.0s "哇 电鳗发电机"——泥疙瘩擦亮变蓝色电鳗发电机（科技感道具）
  - 6.0–8.0s 肥大哥背心拖鞋挤上前："到我了 到我了 什么"，掏出自己的泥疙瘩
  - 8.0–10.5s "是海水过滤器"（金色饮水机造型+绿液）；口播补充"3天前 进入疯狂水世界"
  - 10.5–13.9s 反应镜头：卷发大妈+白裙小姐姐惊恐；"进入顶级庇护所" "怎么可能" "水世界打捞到的"
  - 13.9–17.6s 反转冲突：安检员抡锤砸开金色机器——"敢拿假货装大款"，里面是金碗碎片；肥大哥怒吼"你调换我的包"
  - 17.6–18.8s "下去吧你"一脚踢下水；金碗碎片漂在水面收尾
- 笑点结构：排队亮宝递进 → 主角炫耀 → 被当众拆穿是假货 → 物理惩罚落水

### 档案 B：《疯狂秘境》（视频二，17.1s，修仙版迭代，720x1280@30fps）

- 场景：修仙山水仙府，水面栈道排队；金袍长老持发光葫芦鉴定法宝（原片顶部有 LV/功德 UI——新版一律不做 UI）

- 迭代要点（用户亲自验证过的范式，必须延续）：
  1. 逐拍镜像原片结构，只换世界观皮相
